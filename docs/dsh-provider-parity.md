# T3 提供商能力与 DSH 对齐审计

**结论：DSH 与 Codex、Antigravity、Pi、Cursor 部分等价。** DSH 支持模型选择、工具执行、线程委派和子线程结果回传。T3 桥支持运行中追加文本，隔离会话探测成功后支持生成线程标题。T3 桥与官方桥均已实测支持会话回退和续写。已关闭会话的历史快照读取仍有差距。参照驱动中只有 Cursor 支持 `t3_background_wait`，原生删除由 ACP-Registry 按代理能力提供。Codex、Antigravity、Pi 均无这两项，不计为 DSH 相对四家的普遍差距。

基线为 `feat/dsh-plugins` 的 `e4f09b453fe6d12581513793e4287b2e486c5752`。以下“支持”指该行定义的能力。单元格的文件与行号指向此提交。“部分”列出限制。缺少可选字段时单独注明客户端默认或替代路径。DSH 一栏方括号内的测试名对应末节复跑命令。参考列主要是代码审计，参考机型、账号和云端模型没有逐一实机认证。

| 维度         | 判定                       | 用户可观察的边界                                                                                                         |
| ------------ | -------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| A 能力快照   | 部分等价                   | 有分组模型、effort、命令、技能、上下文和权限菜单。缺原生 load/delete、账号额度、内建登录/安装、可执行的版本更新。        |
| B 会话适配器 | 部分等价                   | 开会话、发消息、运行中 steer、中断、恢复、压缩和审批可用。支持会话回退及保留历史续写，已关闭会话的历史快照读取仍有差距。 |
