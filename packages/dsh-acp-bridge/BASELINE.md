`codec.ts` translates values. The T3 extension uses the optional `commands` and `skills` registries for ACP advertisements and routes slash commands through `commands.execute`. It translates advertised `$skill` tokens to the installed `dsh-tool-skill` plugin?s `/skill` gesture. Optional descendant methods, filesystem path conversion, image storage and usage metering are checked before use. Missing descendant methods emit a warning and preserve root settlement, flush and disposal. Exceptions from present teardown operations still reach the caller.

## Reproducing the checks

Before using the T3 bridge, run `pnpm --filter @t3tools/dsh-acp-bridge build`. Git ignores `packages/*/dist`. If the bridge artifact is missing, `provider-dsh` warns and falls back to the official bridge. The build verifies the artifact has no static DSH or ACP SDK imports. Both scripts use the provider's launch, environment and overlay preparation. The default on Windows is the installed DeepSeek Harness desktop CLI. `T3_DSH_PARITY_CLI` can select an equivalent executable.

- `node packages/dsh-acp-bridge/scripts/commands.mjs` checks registration, dispatch, model request counts and skill instruction injection against a real T3 bridge with a loopback model.
- `node packages/dsh-acp-bridge/scripts/e2e-offline.mjs` starts a loopback Responses SSE server and two ACP sessions with private temporary DSH homes. It requires the Windows ACP profile with `pwsh` available. It checks the actual fixture contents returned by the tool, text assembled from SSE deltas, and the ordered JSON-RPC transcript including list, close and resume. The ACP bridge emits committed message chunks. SSE token boundaries are internal to the model adapter.
- `node packages/dsh-acp-bridge/scripts/parity.mjs` uses the synced local profile and selects `pixel` when available, or `T3_DSH_PARITY_MODEL` if specified. It issues one arithmetic prompt per bridge. Each bridge must return `end_turn` and non-empty assistant text. A route error, timeout or upstream failure exits nonzero. The live comparison ignores per-call token counts and compares the context window size and the full ordered transcript after accounting for one T3 command advertisement per new/resumed session. Set `T3_DSH_PARITY_MODEL=skip` to explicitly skip the live check.
